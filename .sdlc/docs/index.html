SDLC Pipeline Engine v3.8

AI-powered task management for CodeIgniter 3 projects.
Guides agents through structured phases: discover → plan → code → test → review → commit.

What It Does

  • Discovery: One command scans your codebase (LCA + RAG + Brain) and generates a complete analysis
  • Phase Enforcement: Prevents agents from coding before planning, or committing before review
  • Anti-Drift: Keeps AI focused — no tangents, no skipping steps
  • Knowledge Reuse: Searches bug recipe library before re-investigating known issues
  • Quality Scoring: Auto-grades discovery completeness (0-100%)

Quick Start

# 1. Start a task
python .sdlc/engine/cli.py start -t fix -m reports -s "Cashbook not showing opening balance"

# 2. Run discovery (auto-analyzes codebase)
python .sdlc/engine/cli.py discover

# 3. Follow the pipeline — AI reads phase instructions automatically
python .sdlc/engine/cli.py what-next
python .sdlc/engine/cli.py step-done

Requirements

  • Python 3.10+
  • Git
  • LCA (Logimax Code Analyzer) — pip install -e logimax-devtools/backend/lca_core
  • Optional: ChromaDB + sentence-transformers (for RAG semantic search)
