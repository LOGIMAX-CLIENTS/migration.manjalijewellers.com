# Catalog Form UX — Mandatory Field Markers + Search Text Sizing

## Metadata
- **Pattern ID**: PAT-CTG-005
- **Severity**: LOW
- **Modules Affected**: Retail Catalog (Design Mapping, any listing page with DataTables search)
- **Auto-fixable**: Yes

## Client Scope
- **Applies to**: ALL
- **Reason**: Universal UX improvement for form clarity and search visibility

## Created By
- **Developer**: Antigravity (Black Horest) / Karthi
- **Client**: Source (retailsource)
- **Date**: 2026-06-08
- **Source Bug ID**: Design Mapping Bug #10, #16, #18

## Symptom
1. Users don't know which fields are mandatory — no visual indicators on required Select fields
2. DataTables search box text appears too small and hard to read
3. Form field boxes have inconsistent sizes and label weights

## Root Cause
1. `<label>` elements for required Select fields lack mandatory asterisk markers
2. DataTables default search input inherits small font-size from global styles
3. No CSS normalization for Select2 container heights and label font-weights in form groups

## Detection
```command
grep -n "Select Product</label>" admin/application/views/master/ret_product/product_mapping.php
grep -n "Select Design</label>" admin/application/views/master/ret_product/product_mapping.php
grep -n "subdesign_list_filter" admin/application/views/master/ret_product/product_mapping.php
```

## Files
- `admin/application/views/master/ret_product/product_mapping.php`

## Fix

### Part 1: Add mandatory markers to labels

#### Before
```html
<label>Select Product</label>
<label>Select Design</label>
```

#### After
```html
<label>Select Product <span class="text-danger">*</span></label>
<label>Select Design <span class="text-danger">*</span></label>
```

### Part 2: Add CSS block for search and field consistency

#### Before
```html
<div class="content-wrapper">
```

#### After
```html
<div class="content-wrapper">

<style>
  /* Make DataTables search text visible with proper font size */
  #subdesign_list_filter input[type="search"] {
    font-size: 14px;
    padding: 4px 8px;
    min-width: 200px;
  }
  /* Consistent form field sizing */
  .box-body .form-group.tagged .select2-container {
    min-height: 34px;
  }
  .box-body .form-group.tagged label {
    font-weight: 600;
  }
</style>
```

## Verification
1. Navigate to Design Mapping page
2. Verify red asterisks (*) appear next to "Select Product" and "Select Design" labels
3. Check the DataTables search box — type text and verify it's readable (14px font)
4. Verify all Select2 dropdowns have consistent height
5. Verify form labels appear with consistent font weight (600)
6. Test on different screen sizes to ensure no overflow

## Notes
- Use `text-danger` class for the asterisk — this is Bootstrap standard and consistent with `<span class="error">*</span>` used in modal forms
- The `#subdesign_list_filter` ID is auto-generated by DataTables as `{tableId}_filter` — adjust for each table
- This CSS fix is page-specific (inline `<style>` block) to avoid global side effects
- For broader application, consider adding these rules to a shared CSS file
- The `min-height: 34px` matches Bootstrap's default input height for visual consistency
